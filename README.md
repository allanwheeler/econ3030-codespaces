# ECON 3030: Analyzing Economic Data

A browser based Python lab for California State University, Bakersfield. Learn to load, filter, summarize, and chart economic data with Polars and Altair. No software installation, terminal commands, or Git knowledge needed.

## Start with your own copy

1. Sign into GitHub. On the instructor's repository, click **Fork**, select your personal account as owner, then **Create fork**.
2. Check that the repository heading starts with **your username**.
3. On your fork, choose **Code > Codespaces > Create codespace on main**. If the branch has another name, use that branch. Wait for setup to finish.
4. Open `notebooks/01_getting_started.ipynb` in the left Explorer. Choose **Python 3.12 (ECON 3030)** if asked for a kernel. Run the first cell with its triangle button.

**[Your Codespaces dashboard](https://github.com/codespaces)** lets you reopen or stop an existing Codespace. It does not create a new one. Create your first Codespace from your fork using the steps above.

Follow the [student guide](STUDENT_GUIDE.md) to complete, download, and submit the notebook to Canvas. The optional `examples/interactive_window_demo.py` shows another way to run Python.

All 50 observations in `data/state_unemployment.csv` are synthetic teaching data for five states, 2014 through 2023. They are not official statistics. Values such as `5.2` mean 5.2%.
